# Оконный завод — новый сайт

Многостраничный сайт на Astro. Собирается в статический HTML: работает на любом
хостинге, включая обычный shared с FTP. Ни PHP, ни базы данных не требуется.

```bash
npm install      # один раз
npm run dev      # локальная разработка, http://localhost:4321
npm run build    # сборка в dist/ — эту папку и заливать на хостинг
npm run preview  # посмотреть собранное перед заливкой
```

### Главная находка

Самый популярный отзыв на VL.RU — **негативный, и он про цену**: клиент пишет,
что заявленные 6900 ₽/м² превратились в 20 000 ₽, а смету дали без расшифровки.

Новый сайт отвечает на это прямо: страница цен с вилками, калькулятор с разбивкой
по строкам и отдельный шаг в процессе — «смета по пунктам, без строки „прочие
работы“». Это не абстрактное улучшение, а ответ на конкретную публичную претензию.

## Визуальное направление

Собрано по разбору референсов заказчика (Octaboot, Raman Studios / Alsamar Pools)
и рекомендациям установленного скилла `ui-ux-pro-max`.

**Что взято из референсов напрямую:**

| Приём | Как реализовано |
|---|---|
| Кадр во весь экран, продукт — его единственное содержимое | `.hero` на `100svh`, WebGL-сцена во всю площадь |
| 3–5 слов на первом экране | Рубрика, два слова антиквой, строка характеристик, одна ссылка. Всего 4 элемента |
| Тонкая высококонтрастная антиква | Playfair Display **400** (не 900), 190px, трекинг −0.038em |
| Тип поверх кадра, слева | Диагональное затемнение слева, тип поверх |
| Ссылка вместо кнопки | Подчёркнутая строка со стрелкой, как «(RESERVE)» у Octaboot |
| Акцентного цвета почти нет | 7 элементов на всю страницу: звёздочка обязательного поля, галочка успеха, две рубрики |
| Чистый кадр без текстур | Зерно убрано — в референсах его нет |
| Навигация из нескольких слов | Логотип, «Услуги», три пункта, кнопка |

**Печатная система под контент** (из `ui-ux-pro-max`, стиль Editorial Grid / Magazine):

- Playfair Display 400 · Source Serif 4 · JetBrains Mono — гротеска в интерфейсе нет
- линейки четырёх толщин: 1px волосяная, 1px тонкая, 2px жирная, 4px тяжёлая
- буквица, врезка-цитата, колоночный набор
- реестр направлений полноширинными строками вместо плиток
- асимметричная сетка 5/7, 7/5, 4/8, нулевые скругления, без теней

### Как устроена 3D-сцена

Файл `src/components/WindowScene.astro`. Меняются там же размеры окна (`W`, `H`),
ширина профиля (`F`), импост (`I`), цвет профиля и фурнитуры.

Движок весит 184 КБ в сжатом виде и **загружается отдельным файлом только
когда первый экран рядом** — начальная загрузка страницы за него не платит.
Сцена не запускается вовсе, если: нет WebGL 2, экран уже 560 px, или
пользователь включил «уменьшить движение» (тогда рисуется один статичный кадр).
Во всех этих случаях остаётся CSS-композиция окна, которая лежит слоем ниже.

Отдельно обработана потеря контекста WebGL — при ней возвращается
CSS-композиция, чтобы первый экран не оказался пустым.

Если 3D не нужен совсем — удалите строку `<WindowScene />` из
`src/components/Hero.astro` и `npm uninstall three`. Первый экран останется
рабочим на CSS.

**Важно про массовую аудиторию.** Тёмный сайт с антиквой сильно отстраивает
от всех конкурентов в нише, но это премиальная подача. Если у завода много
возрастных клиентов, стоит замерить конверсию первые пару недель. Дизайн-система
токенизирована: переключение на светлую тему — это правка одного блока
`:root` в `src/styles/global.css`, вёрстку трогать не придётся.

## Фотографии

Реальных снимков производства и объектов у нас нет, поэтому на их местах стоят
**слоты-плейсхолдеры** — тёмная витрина с лучом света, оформленная как часть
макета, с подписью, какой именно кадр туда нужен. Подставлять сгенерированные
картинки вместо фото цеха мы не стали: если клиент однажды поймёт, что цех
на сайте нарисованный, он перестанет верить и остальному тексту.

**Что нужно снять:**

- Цех: линия сварки ПВХ, участок стеклопакетов, сборка алюминия, склад готовых изделий
- Объекты: 5–6 работ с планом «до» и «после», желательно из разных городов
- Люди: бригада на монтаже, портреты сотрудников из блока команды
- Офисы: въезд на производство с вывеской, вход в офис продаж
- Отдельно: узлы крупным планом — монтажный шов, порог подъёмно-сдвижной створки, вынос по подоконнику

Под выбранное направление снимать нужно **на тёмном фоне с направленным
тёплым светом** — тогда фотографии встанут в макет без переделки.
Как только они появятся, компонент `PhotoSlot` заменяется на `<img>`
с `loading="lazy"`, `width`, `height` и осмысленным `alt`.

## Подключить приём заявок

Форма сейчас отправляет заявку в консоль браузера — это заглушка, чтобы можно
было показать сайт до подключения бэкенда. Чтобы заявки уходили по-настоящему,
задайте эндпоинт в `src/layouts/Base.astro` перед закрывающим `</body>`:

```html
<script>
  window.LEAD_ENDPOINT = 'https://ваш-домен/api/lead';  // принимает JSON POST
  window.YM_ID = 66211795;                              // счётчик Яндекс.Метрики
</script>
```

Форма отправит JSON: `name`, `phone`, `service`, `city`, `when`, `note`, `page`.
Годится любой приёмник — PHP-скрипт на хостинге, Telegram-бот, вебхук CRM.

**Цели в Метрике.** Форма и калькулятор уже вызывают `ym(ID, 'reachGoal', ...)`
с идентификаторами `lead_submit` и `calc_to_lead`. Создайте эти две цели
в интерфейсе Метрики — и появится ответ на вопрос, сколько заявок даёт сайт.
На действующем сайте счётчик стоит, но целей нет, поэтому реклама крутится вслепую.

## Публикация

Собранная папка `dist/` — это готовый статический сайт.

**Российский хостинг (рекомендуется — Timeweb, Beget, Selectel).**
Залить содержимое `dist/` в корень сайта по FTP. Обязательно включить HTTPS
и редирект с HTTP. Действующий сайт сейчас не отвечает с внешних адресов —
проверьте, не стоит ли на хостинге гео-фильтр: он отсекает не только ботов,
но и поискового робота Google.

**Быстрый показ заказчику.** Netlify или Cloudflare Pages: перетащить папку
`dist/` в браузер — получите ссылку за минуту. Для боевого сайта в Приморье
они не годятся из-за задержек, но для демонстрации подходят.

**Настройки сервера, которые стоит добавить:**

- HTTPS и редирект `http → https`
- gzip или brotli для `.html`, `.css`, `.js`, `.svg`
- `Cache-Control: max-age=31536000, immutable` для `/_astro/*`
- Страница `404.html` как обработчик ошибки 404

После публикации: добавить сайт в Яндекс.Вебмастер и Google Search Console,
отправить `sitemap-index.xml`, проверить микроразметку через валидатор Яндекса.
